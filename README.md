
# Meridian Pivot Sprint – Individual Learning and Prototype

## Project Overview

This project was developed as part of the Meridian Pivot Sprint individual learning and prototype assignment.

The initial prototype focused on learning and implementing webhooks using Node.js and Express. The project was later extended to support the pivot requirements by adding stock data and a simple frontend interface.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- HTML/CSS
- JSON
- Webhooks
- Git and GitHub

## Main Components

### Backend

The backend is implemented in `app.js` using Node.js and Express.

It includes:

- An Express server
- JSON request handling
- A `/webhook` endpoint
- Input validation
- Stock update handling
- JSON responses

### Frontend

The frontend is contained in the `public/` directory and provides the user interface for interacting with the application.

### Stock Data

The `stock-data.json` file contains the stock information used by the application.

### Learning and Blocker Journal

The `learning-blocker-journal.md` file documents:

- Learning objectives
- Resources consulted
- Development activities
- Blockers encountered
- Troubleshooting steps
- Solutions implemented
- Testing and validation
- Lessons learned
